# 坦克大战 · Tank Battle

一个使用纯 HTML5 Canvas + JavaScript 编写的经典坦克大战（Battle City）游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- **移动**：`W A S D` 或方向键 `↑ ← ↓ →`
- **开火**：`空格`
- **暂停**：`P`
- **开始 / 重开**：`Enter` 或 `R`

## 特色

- 经典 Battle City 地图：砖墙（可摧毁）、钢墙（不可摧毁）、水域、草丛（遮挡视线）
- 保护基地 ★，基地被摧毁则游戏结束
- 多种敌人，敌军数量随关卡递增
- 子弹碰撞、粒子爆炸特效、WebAudio 音效
- 计分、生命、关卡系统

## 在线游玩

在浏览器中打开 [index.html](./index.html)，或使用 GitHub Pages 部署。

## 本地运行

直接双击 `index.html`，或在任意静态服务器中打开，例如：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
